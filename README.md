# Work in progress #

Package manager that has no name yet, which will be used on my LFS.

It's philosophy is:

- Compile from source whenever possible
- Avoid manually importing packages (if possible)
- Be FHS complaint
- Be as transparent as possible, though this doesn't mean that it will be easy to work with

I'm currently working on querying PKGBUILD files from arch linux packages and parsing them.


`Dependencies:`
- curl
